Acme Analytics documentation

Acme Analytics helps teams understand product usage. This page explains installation, authentication, and how to query events from the public API.

Getting started

Install the CLI, authenticate with an API token, then run your first query.

Installation

Download the binary or install from npm. The CLI works on macOS, Linux, and Windows.

API overview

Every request uses HTTPS. Responses are JSON. Errors include a stable machine-readable code.
